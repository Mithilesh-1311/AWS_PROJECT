# EOG Intent

EOG Intent is a research application for early eight-direction classification of recorded eye movements. Subtitle: EARLY EYE-MOVEMENT INTELLIGENCE. Full title: Low-Latency EOG-Based Early Intent Detection for Eye Movements.

Users inspect recordings, understand calibration/onset/window limits, run a saved classifier, replay recorded chunks and compare reproducible experiments. Success is a traceable result with source, configuration, sample timing and evaluation scope. This is not a clinical device or live sensor interface.

Primary flow: dataset → processing → early window → prediction → recorded replay → evaluation/export. All research screens use Operate mode: compact controls, legible charts, keyboard access and explicit unavailable/error states. No personal or institution details in the UI. The master prompt supplies the task, visual direction and acceptance gates and authorizes reversible implementation without another design confirmation.
